A sleek, editorial consulting theme for boutiques, advisory firms and strategy practices.

== Description ==

Konzult is a design-led theme for consulting businesses. It ships with a complete homepage, a full set of inner-page templates, a self-hosted type system, a restrained motion layer, and a starter template for free Elementor.

The theme works with or without Elementor. Pages built with Elementor render inside the theme header and footer; Elementor Canvas and Full Width templates are available for landing pages.

== Installation ==

1. Upload the konzult folder to /wp-content/themes/ or install the ZIP through Appearance > Themes.
2. Activate the theme.
3. Visit Settings > Permalinks and save once.
4. Configure menus and options under Appearance > Customize > Konzult options.

== Frequently Asked Questions ==

= Does this theme require Elementor Pro? =

No. The theme is designed for free Elementor. Header, footer and blog templates are built in PHP. If Pro is active, the theme registers the core Theme Builder locations so you can override them visually.

= Are the fonts included? =

Yes. Instrument Serif and Inter are self-hosted as woff2 files under the SIL Open Font License. No external font requests are made.

= Can I change the accent colour? =

Yes, under Appearance > Customize > Konzult options > Brand colour.
